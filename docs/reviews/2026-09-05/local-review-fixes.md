## 验证边界

本轮没有运行 GitHub 在线工作流、真实 Docker 完整迁移/安装 E2E、浏览器交互或整套真实 Redis ACL/TLS/缓存恢复测试。Redis 清理回归执行真实 JUnit 生命周期、控制 Redis 外部边界；迁移清理回归使用有状态 Docker 替身。PostgreSQL 14/18 则使用真实本地数据库，不能将这三类证据混称为完整部署验收。

失去租约且没有提交标记的任务可能持续处于结果待确认状态，原事务仍可能提交。此时前端继续轮询；运维需核对原实例和数据库事务，确认结果前不要重复导入。查询不再将未知结果误报为事务失败。
